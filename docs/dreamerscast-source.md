# Источник «Dream Cast»

Балансер dreamerscast.com (студия озвучки Dream Cast). Модули `source/dreamerscast/{domain,data}` необязательные, подключаются
только вместе с `source/availability` (см. `settings.gradle.kts`, в `app/build.gradle.kts` нужны `:source:availability:data` и
`:source:dreamerscast:data`). Серверная часть и расписание обхода: `YummyTV_API/docs/dreamerscast.md`.

## Как работает

- `DreamerscastExtraVideoRepository` берёт наличие через `FindSourceAvailabilityUseCase("dreamerscast", …)`: `key` =
  `{id}-{slug}`, `url` = `https://dreamerscast.com/home/release/{key}`. Видео `1..episodesAvailable` с
  `iframeUrl = source://dreamerscast/{slug}/{episode}`, озвучкой и плеером «Dream Cast», отрицательным id (прогресс локальный).
- `DreamerscastRepositoryImpl` разрешает ссылку при воспроизведении:
    1. `GET /home/release/{slug}` → в странице `new Playerjs("#2…")`.
    2. Строка расшифровывается: после `#2` идёт base64 JSON `{"file":[{"title":"Серия 1","file":"…"},…]}` со вставками-«мусором»
       `//` + 86 символов + `==` (ровно 90 символов). Вставки бывают **вложенными**, поэтому снимаются по очереди: от первого
       `==` назад на 88 символов, пока не останется только финальный паддинг. Проверено на 16 страницах.
    3. Серия — по числу в названии («Серия 5»), а без числа (фильм) — по порядку. В `file` лежит
       `«…/manifest.mpd or …/hls/…/master.m3u8»`: берётся HLS-мастер на `play.dreamerscast.com`.
    4. `GET` мастера → варианты 1080/720/480 (звуковая дорожка без `RESOLUTION` пропускается) → карта качеств по возрастанию.
- Заголовки не нужны: страница, мастер и плейлисты отвечают без `Referer`; ссылки не подписаны.
- Нет страницы, серии или HLS-ссылки — `Unavailable` с локализованным текстом (en/ru/uk), сетевой сбой — `Failed`.

## Ограничения

- **Видео в AV1**: в мастере `CODECS="av01…,mp4a.40.29"`. Устройства без аппаратного (или быстрого программного) декодера AV1
  не проиграют серию; запасного варианта сайт в HLS не даёт (есть DASH, но с тем же видео).
- Формат обфускации Playerjs — наблюдение, а не контракт: при его смене разбор вернёт `null` и серия покажется недоступной
  (на сервере сработает тревога парсинга по странице релиза только если сломается разбор самой страницы).
- Озвучка одна («Dream Cast»): у релиза один плейлист, состав озвучивающих сайт показывает текстом.
- Для не вышедших серий плеера нет: сервер отдаёт только `episodesAvailable` > 0.
