# Конфиги Varioqub

Удалённый конфиг (Яндекс Varioqub) живёт в модуле `core:featuretoggle`. Все ключи заданы в
`FeatureFlags.kt` (плюс `anime4k_enabled` в `source/anime4k/data/.../flag/Anime4kFeatureFlag.kt`).
Читаются через `FeatureToggleProvider`: при ошибке или неинициализированном Varioqub отдаётся
значение по умолчанию, поэтому пустое значение везде означает «поведение как в сборке».

Клиент берётся из `local.properties` (`yummytv.varioqubClientId`). Конфиг подтягивается при запуске
и при каждом возврате приложения на передний план (throttle: 60 с в release, 2 с в debug).

## Когда значение вступает в силу

| Группа                                   | Момент применения                                                     |
|------------------------------------------|-----------------------------------------------------------------------|
| Адрес и токен сайта                      | **Один раз при запуске**, со следующего запуска после fetch           |
| Объявление, строка-сообщение, min-версия | На лету: по `FeatureToggleUpdateObserver.updates` после активации     |
| Резервное обновление APK                 | При каждой проверке обновлений / скачивании                           |
| `anime4k_enabled`                        | При обращении к источнику                                             |

## Ключи

### Версия приложения

| Ключ                       | Тип    | По умолчанию | Описание                                                                                                   |
|----------------------------|--------|--------------|------------------------------------------------------------------------------------------------------------|
| `app_min_supported_version`| string | `""`         | Минимальная поддерживаемая версия. Ниже неё открывается обязательный экран обновления. Пусто = ограничения нет. |

### Объявление (диалог на главной)

| Ключ                   | Тип    | По умолчанию | Описание                                                                              |
|------------------------|--------|--------------|---------------------------------------------------------------------------------------|
| `announcement_id`      | string | `""`         | Идентификатор. Смена значения снова показывает диалог всем. Пусто или `0` = выключено. |
| `announcement_title`   | string | `""`         | Заголовок. Пусто = без заголовка.                                                     |
| `announcement_message` | string | `""`         | Текст. Пусто = диалог не показывается.                                                |
| `announcement_button`  | string | `""`         | Текст кнопки. Пусто = локальная строка «ОК».                                          |

Прочитанным считается `announcement_id`, он хранится в DataStore (`last_seen_announcement_id`).

### Строка-сообщение (не диалог)

| Ключ                 | Тип    | По умолчанию | Описание                                                                                           |
|----------------------|--------|--------------|----------------------------------------------------------------------------------------------------|
| `status_message_text`| string | `""`         | Текст строки на главной под плашкой «нет сети» (mobile и TV). Пусто = не показывается. Не закрывается. |

### Сайт YummyTV (API и токен)

| Ключ               | Тип    | По умолчанию | Описание                                                                                                    |
|--------------------|--------|--------------|-------------------------------------------------------------------------------------------------------------|
| `site_api_base_url`| string | `""`         | Базовый URL API (`https://…/api`). Пусто, не `https://` или равен встроенному = остаётся встроенный.        |
| `site_api_token`   | string | `""`         | Секрет подписи запросов 4K. Пусто или равен встроенному = остаётся `API_SIGNING_SECRET` из сборки.          |

Применяется одним вызовом `SiteApiConfig.apply` в `YummyTvApplication.setupFeatureToggles()`;
до перезапуска приложения не меняется. Адрес используют `Anime4kApi` и `YummyEpisodesApi`.

### Резервное обновление APK

Используется только если GitHub Releases недоступен (ошибка, таймаут 3,5 с, пустой список), а также
как вторая ссылка при ошибке скачивания основной.

| Ключ                       | Тип    | По умолчанию | Описание                                                                    |
|----------------------------|--------|--------------|-----------------------------------------------------------------------------|
| `update_fallback_apk_url`  | string | `""`         | Прямая ссылка на APK, только `https://`.                                    |
| `update_fallback_version`  | string | `""`         | Версия этого APK; сравнивается с текущей через `isVersionNewer`.            |
| `update_fallback_changelog`| string | `""`         | Описание изменений для диалога обновления.                                  |

Версия берётся из флага, а не из файла: она должна соответствовать реальному APK. Установку
проверяет система (подпись и versionCode).

### Источники

| Ключ            | Тип     | По умолчанию | Описание                                                                                 |
|-----------------|---------|--------------|------------------------------------------------------------------------------------------|
| `anime4k_enabled`| boolean | `true`       | Источник 4K. `false` отключает его удалённо. Без рекламного блока и секрета подписи источник скрыт и при `true` (см. модуль). |

## Добавление нового флага

1. Объявить в `FeatureFlags.kt` (`StringFlag`/`BooleanFlag`) с KDoc и безопасным значением по умолчанию.
2. Читать через `FeatureToggleProvider`; для реакции на лету подписаться на `FeatureToggleUpdateObserver.updates`.
3. Добавить строку в эту таблицу.
