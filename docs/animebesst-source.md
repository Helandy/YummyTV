# Источник «Animebesst»

Балансер anime1.best (движок DLE). Модули `source/animebesst/{domain,data}` необязательные, подключаются только вместе с
`source/availability` (см. `settings.gradle.kts`, в `app/build.gradle.kts` нужны `:source:availability:data` и
`:source:animebesst:data`). Серверная часть и расписание обхода: `YummyTV_API/docs/animebesst.md`.

## Как работает

- `AnimebesstExtraVideoRepository` берёт наличие через `FindSourceAvailabilityUseCase("animebesst", …)`: `key` = slug страницы,
  `url` = `https://anime1.best/anime1-online/{slug}.html`, `mirrors` — та же страница на зеркалах
  (`ab2`/`ab3`/`ab4.animebesst.org`). Видео `1..episodesAvailable` с
  `iframeUrl = source://animebesst/{slug}/{episode}?h={хост},{зеркало},…` (основной хост первым), озвучкой и плеером
  «Animebesst», отрицательным id (прогресс локальный). Хосты зашиты в адрес серии, чтобы при воспроизведении страницу можно было
  открыть через зеркало.
- `AnimebesstRepositoryImpl` разрешает ссылку при воспроизведении:
    1. `GET https://{хост}/anime1-online/{slug}.html`; при сетевом сбое (таймаут, обрыв) — следующий хост, 404 — тоже следующий.
    2. `var videoList = [{"id":"1","link":"//plus4.aff1best.org/vod/96032"},…]` → ссылка серии; метка `1-2` покрывает
       обе серии; принимается только `https://{хост}/vod/{число}`.
    3. `GET` страницы плеера → `new Playerjs({ file:"…/hls/index.m3u8" })`.
    4. `GET` HLS-мастера → варианты `1080`/`720` с **относительными** адресами (`./1080/index.m3u8`, считаются от адреса
       мастера) → карта качеств по возрастанию.
- Заголовки не нужны: страница, плеер, мастер, плейлисты и сегменты проверены без `Referer`. Ссылки не подписаны.
- Нет страницы, серии или файла — `Unavailable` с локализованным текстом (en/ru/uk), сетевой сбой на всех хостах — `Failed`.

## Ограничения

- Проверено вживую 28.10.2026 с основного хоста `anime1.best`; зеркала `ab2`/`ab3`/`ab4` из сети проверки не открывались
  (таймаут подключения), поэтому переход на них проверен только тестами.
- Плеер сайта живёт на отдельном домене (`plus4.aff1best.org`): если закрыт он, а не сайт, зеркало не поможет.
- Озвучка одна («Animebesst»): `videoList` не различает озвучки.
- Сдвоенная серия (`1-2`) в списке серий занимает один элемент, поэтому счёт `episodesAvailable` с сервера может быть на
  единицу меньше номера последней серии.
