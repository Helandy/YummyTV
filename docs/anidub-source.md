# Источник «AniDub»

Балансер online.anidub.com (дубляж студии АниДаб). Устроен как [AiLiberty](ailiberty-source.md):
модули `source/anidub/{domain,data}`
необязательные, подключаются только вместе с `source/availability` (см. `settings.gradle.kts`, в
`app/build.gradle.kts` нужны
`:source:availability:data` и `:source:anidub:data`). Серверная часть и расписание обхода:
`YummyTV_API/docs/anidub.md`.

## Как работает

- `AniDubExtraVideoRepository` берёт наличие через `FindSourceAvailabilityUseCase("anidub", …)`
  (один общий запрос на все балансеры) и строит видео `1..episodesAvailable` с
  `iframeUrl = source://anidub/{slug}/{episode}`, озвучкой и плеером «AniDub», отрицательным id
  (прогресс локальный). Сервер отдаёт только тайтлы с плеером ladonyvesna.
- `AniDubExtraStreamRepository` разрешает ссылку в момент воспроизведения (подписанные ссылки CDN
  живут около 2 часов), `AniDubRepositoryImpl`:
    1. `GET https://online.anidub.com/{slug}.html` → `<iframe src=".../index.php?v=/sNN/<hash>">`:
       хост плеера (`player26.ladonyvesna2005.info`, он меняется) и хэш; нет iframe — только Sibnet,
       серии нет.
    2. `GET {player}/index.php?v=/{hash}&playlist` (Referer — сайт) → серии `"link":"/sNN/…"` с
       `"label":"N серия"`. Серия — по номеру; единственная запись (фильм, «0 серия») — серия 1;
       плейлиста нет — серия 1 это хэш самого плеера.
    3. `GET {player}/vid.php?v=/{hash серии}` (Referer — плеер) → HLS-мастер. **Поле `RESOLUTION` в
       нём врёт** проверено `ffprobe`: вариант с `RESOLUTION=1280x720` на деле 1920x1080), поэтому
       качество берётся из имени варианта: `fhd.mp4` — качество релиза из `event-filename` плейлиста
       (`…HD1080p…` → 1080p, по умолчанию 1080p), `hd.mp4` — 720p,
       `sd.mp4` — 480p, прочие пропускаются. Плееру уходит карта качеств по возрастанию (лучшее по
       умолчанию — последнее); не разобралось — играет сам мастер адаптивно.
- **Подпись ссылок CDN привязана к User-Agent**, с которым запрошен мастер (с другим UA и плейлист,
  и сегменты — 403; проверено). Поэтому вся цепочка идёт UA из `BrowserUserAgentProvider`, и он же
  вместе с `Accept: */*`, `Referer: {player}/` и `Origin: {player}` уходит плееру в `Stream.headers`
  (`PlayerDataSourceFactory` применяет их ко всем запросам HLS, включая сегменты).
- **Узлы CDN ротируются** (`cdn1/3/5.anivids.link`), часть нерабочая: мастер переспрашивается до 8
  раз, пока не выпадет живой узел. `cdn1.anivids.link`
  считает плохим и пропускает; остальные проверяются пробой первого варианта (в ответе должен быть
  `#EXTM3U`), результат пробы помнится 20 минут. Если живого узла не нашлось, отдаётся последний
  полученный вариант.
- Нет тайтла или серии — `Unavailable` с локализованным текстом (en/ru/uk), сетевой сбой — `Failed`.

## Ограничения

- **Sibnet не играется**: у ~72% каталога (почти все тайтлы старше 2018) на сайте только Sibnet, они
  в приложении не появятся. Добавить можно, положив в видео ссылку Sibnet и дав её существующему
  `SibnetExtractor`; для этого нужно проверить, что extra-видео с не-`source://` ссылкой проходит
  весь конвейер, либо писать резолв в самом модуле.
- Список «плохих» узлов (`cdn1.anivids.link`) зашит в `AniDubPlaylistUtils.kt`;
- Хост сайта (`https://online.anidub.com`) — константа в `AniDubPlaylistUtils.kt`; хост плеера
  берётся со страницы каждый раз.
- Сезоны AniDub — отдельные посты с одинаковыми русскими названиями; сверка опирается на год и число
  серий, неоднозначность даёт «нет совпадения».
